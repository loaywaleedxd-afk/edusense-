What is EduSense?

One platform. Every stakeholder.

EduSense is a complete university management system built for modern academic institutions. It gives every role — students, lecturers, administrators, and parents — a dedicated, intelligent portal connected to real-time data.

🧠

AI at the Core

Emotion and attention data captured per lecture, per student. Lecturers see live engagement heatmaps, admins get system-wide analytics.

📱

Cross-Device QR Attendance

Lecturer generates a QR on their desktop. Students scan with their phone. Attendance is recorded instantly — no app install required.

🌐

Arabic RTL Support

Full bilingual interface — English and Arabic with complete right-to-left layout switching. Built for Egyptian and Gulf universities.

📊

Rich Analytics

Charts, trend lines, and KPI cards across every role. GPA trends, emotion distribution, attendance patterns, engagement history.

🔔

Automated Alerts

Students at-risk (below 75% attendance) get automatic email alerts. Parents are notified in real time via the parent portal.

🔒

Secure by Design

HTTPS, rate-limited login, session isolation, audit logs for every grade change, fee edit, or enrollment action.

Four Portals

Every role gets their own experience.

Each role sees only what is relevant to them — no noise, no clutter.

🎓

Student Portal

Access: personal data only

  • Dashboard with live GPA, attendance, and emotion scores
  • QR check-in from mobile without needing an account login
  • Emotion and engagement history per course
  • Grade appeals with real-time status tracking
  • Office hours booking and fee history
  • PDF transcript download, digital ID card
  • GPA calculator, timetable, graduation roadmap
  • Academic calendar and study resources
👨‍🏫

Lecturer Portal

Access: own courses and students

  • Live session control with QR attendance generation
  • Real-time emotion and attention heatmap per student
  • AI Insights dashboard with engagement trends
  • Grade management and assignment tracking
  • One-click low-attendance email alerts
  • Office hours calendar with booking management
  • Grade appeal review and response workflow
  • Live lecture polls for real-time student feedback
🏛️

Admin Portal

Access: full system

  • System-wide analytics: students, doctors, courses, departments
  • User account creation with automatic email credential delivery
  • Exam management and result publication
  • Full audit log — every action timestamped with actor
  • At-risk student detection and early warning panel
  • Exam proctoring control room
  • Academic advising management
  • Grade appeal final decisions
👨‍👩‍👧

Parent Portal

Access: linked child data only

  • Live attendance and GPA monitoring for their child
  • Automatic notifications when attendance drops below 75%
  • Grade and exam result visibility
  • Emotion and engagement summary per course
  • Contact lecturer or admin directly from portal

Architecture Overview

[ Browser / Mobile ]
↓ HTTPS
[ React SPA — Hostinger ]
↓ REST API (JWT)
[ FastAPI Backend ]
↓ SQL queries
[ SQLite → PostgreSQL ]

[ EmailJS ] ← email alerts
[ QR URL ] ← cross-device check-in

The frontend runs fully standalone as a demo. Connecting the backend enables real multi-user data persistence, JWT-secured sessions, and server-side analytics.
