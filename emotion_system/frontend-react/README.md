# EduSense React (Vite) - Runner

This folder contains a minimal Vite+React setup to render:
- `emotion_system/gui/pages/EduSense.jsx`

## Run
From repo root `d:\download\portal`:

```bat
cd emotion_system\frontend-react
npm install
npm run dev
```

Open the printed local URL (usually http://localhost:5173).

## Notes
- This does not replace the existing portal at `emotion_system/frontend/index.html`.
- It only provides a browser-based React runner for `EduSense.jsx`.
